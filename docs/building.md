# Building OSDS from source

OSDS is an Unreal Engine 5.8 project. How to build it, run it, capture it and test it is in [unreal-building.md](unreal-building.md).

The Godot 1.x build (Godot 4.7.2, `scripts/build-macos.sh`, `scripts/build-windows.sh`) is kept at the git tag `godot-final`: `git checkout godot-final` and follow its `docs/building.md`.

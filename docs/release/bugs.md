## Code review (12 items, verified 2026-11-12 against main 391cffc)

| # | Bug | Verdict and evidence | Owner | Status |
|---|---|---|---|---|
| CR1 | Physics in slow motion when a frame takes more than 33 ms | CONFIRMED: `Config/DefaultEngine.ini` sets no `MaxPhysicsDeltaTime`, so the engine default 1/30 s applies; `PhysLevel.cpp` passes it to `SetUpForFrame`, which clamps the frame's physics time. Below 30 fps the car runs slower than the clock. | physics | fixed on main 8f7aecb (MaxPhysicsDeltaTime 0.1: 12.67 s of physics in 12.66 s at 12 fps) |
| CR2 | No frame cap, VSync or frame pacing; default preset maybe too heavy for a 28 W GPU | CONFIRMED (no `t.MaxFPS`, `r.VSync` or frame-rate limit in the config). Fix in this release: see row G of the checklist. | release | fixed on release/v2.0.0: 60 fps cap (simcruise.FrameCap), Max-Q GPUs start on Medium (cebd03a); row G |
| CR3 | Non-ABS Miata can lock its rear brakes first | CONFIRMED in code: `SimCruiseVehicleSim.cpp` uses fixed `FrontBrakeTorqueNm` / `RearBrakeTorqueNm`, no load-dependent proportioning. The rear-lock-first effect is not measured yet (needs a brake-in-turn bench, ISO 7975). | physics | open (routed to physics): needs a brake-in-turn bench (ISO 7975) and a proportioning model |
| CR4 | Head motion and g-meter jitter | CONFIRMED and FIXED: they differentiated the velocity over the frame time while the 360 Hz physics gives 5, 6 or 7 new steps per 60 fps frame (about 17 % jitter). Now over the physics time (`FSimCruiseDriveTelemetry::SimTimeS`); new test `SimCruise.Gameplay.Camera.PhysicsTimeNoJitter`. | release | fixed |
| CR5 | Manual clutch has no stability cap and never locks | CONFIRMED: the manual branch (`SimCruiseVehicleSim.cpp`, `ManualClutchCouplingNmPerRadPerSecond`) has no 1/(dt x inertia) cap like the automatic's, and the clutch is viscous (it slips by a small amount for ever). | physics | fixed on main 81a88f0 (the manual clutch locks and has a stability cap) |
| CR6 | Banking near tile edges, rural minor roads, seam crests | CONFIRMED for the first two: superelevation runs out to 0 over 30 m (`PinSpanM`) at each tile boundary; `DesignSpeedKmh` gives 0 (no banking) to all roads below secondary. Seam crests: plausible, not measured. | world | fixed on main e35a9a2 (banking across tile seams and on tertiary/unclassified roads) |
| CR7 | Tile install stalls (30-90 ms) | PLAUSIBLE: one tile per frame is installed on the game thread (`SimCruiseWorldStreamer.cpp`, mesh sections and collision). See the soak's worst frame (row K1). The physics-thread trace race was not shown. | world | fixed on main 47a9edf (tile install spread over frames: worst frame 136 -> 35 ms) |
| CR8 | Recover makes the camera swoop | CONFIRMED and FIXED: `ResetVehicle` only queues the reset for the physics thread, so the snap on the request frame came before the car moved. The camera manager now snaps on the frame it sees the car jump (farther than it can drive in the frame, or turn more than 45 degrees). | release | fixed |
| CR9 | Engine-sound limiter fixed at 6950 rpm | CONFIRMED: `FSimCruiseInlineFourSynth::LimiterRpm = 6950` for every car (NB fuel cut 7250, Mustang 5000, C8 6600), so the Mustang and the C8 never sound their limiter and the NB sounds it 300 rpm early. | cars | fixed on main ff35887 (the limiter sounds at each car's fuel cut + 200 rpm; SimCruise.Audio.Limiter) |
| CR10 | Pad: LT brake and LB clutch on the same finger; HUD on L3 | CONFIRMED and FIXED: clutch A (hold), parking brake B (hold), shift up/down RB/LB, gearbox D-pad right, engine restart D-pad left, HUD X. `docs/controls.md`, HUD hints, the self-test and `SimCruise.Gameplay.Input.BindingsMatchControlsDoc` updated. | release | fixed |
| CR11 | Engine braking about half of the real value | CONFIRMED as an estimate: NB friction is 10 + 0.002 x rpm N m (16 N m at 3000 rpm); a 1.8 L engine with a closed throttle (friction and pumping, about 2 bar) gives about 30 N m. | physics | fixed on main 81a88f0 (NB engine braking raised) |
| CR12 | Benches step the game at 1/60 s; drive robot drives no C8 or Mustang | Robot: FIXED, `scripts\drive-robot.ps1` now drives nb2001, nb2001_aaron, mustang65 and meridian_z. Benches: CONFIRMED in part: Chaos steps at 1/360 s, but the game frame is fixed at 1/60 s, so frame-rate-dependent game-thread code is not tested by the benches. | physics | robot fixed (release); the bench game-frame step is open (physics) |

# SimCruise 2.0.0 release report

Release gate for SimCruise 2.0.0, the first full release of the Unreal Engine 5.8 client (Windows). Date: 2026-11-12. Release branch `release/v2.0.0`, on main ff35887; the packaged code is commit 5f21af1: b7ac2de, on which the full gate ran, plus the natural default lens (7267a09, from the cars thread) and the left-stick lens key. For 5f21af1 the gate was re-run in short: Gameplay, Presentation and Drive tests 31/31, `release.ps1` (Shipping, installer, checksums, smoke test), cockpit captures of the 3 cars and the installer test. Test PC: Intel i9-10885H, NVIDIA GeForce RTX 2070 Super with Max-Q Design (laptop GPU), Windows 11.

Result: **full release**. Every row of the driving checklist passes except 3 rows that are written as known issues: the Corvette's 0-60 time (A4), the offline start with the whole network off (I4, not run), and the tuning menu not driven by hand (N6). Details and evidence: [driving-checklist.md](driving-checklist.md), [bugs.md](bugs.md), [evidence/](evidence/).

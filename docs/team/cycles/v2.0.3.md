# Version v2.0.3 (cycle 1; meet 2026-11-14 01:50Z; train model from 03:19Z)

The work now in the lanes is the build stage. Cut-off: the ready check (`docs/team/dev-loop.md`): the coordinator asks each team "are you ready to test?"; when every team says READY TO TEST, the one shared test runs. Then join, test once, fix, re-test once, release.

## One objective per team

| Team | Objective | Lane / thread | Done-when (unit or fast test; the full game test proves it at join) |
|---|---|---|---|
| Car team | Cockpit is right: wheel turns on its column axis, gauges stay fixed, wheel speed and turns lock to lock match the sources | Make the driving and traffic feel real | Rig test: rim vertices within 3 mm of the rest circle after 90°; no steering vertex within 1.2 x dial radius of a dial; turns within 5 % of source |
| World | Scan engine first output: terrain shape and surface (no lime green), real trees from aerial crowns; plus no fall-through on a failed tile and load ahead by speed | Make buildings and terrain detailed and familiar | Seam test, missing-tile test, 130 km/h look-ahead test, road-step test; before/after frame at the owner's hill-road spot |
| Picture | Photo match at High and Ultra (current picture faults) | Make the picture look like a photo | Frame beside a real photo of the same place, luma and colour error noted |
| AI | Legal CPU models for the scan channels, measured | Add local AI that uses only CPU | Each model: licence (weights and training data), CPU ms per tile, error at 3+ random US places |
| Innovation | Proposals 1-2 tested in the Python lab (road cross-section, soil and rock ground) | Research and invent hyper-detail methods | Lab result with metric, pass line and frames |
| QA and tools | One full-test script for the candidate (pre-flight with random places, cockpit lock-to-lock, controller menu) | Review real game output on every test | Script runs all parts in one command and writes one report |
| Production | Train runs; release notes | Build a game team that owns the game | Version file kept; retro written |

Carried in from onboarding: tile with no ground, one-tile reach at speed, climate boxes, untagged gravel, no random-place release gate.

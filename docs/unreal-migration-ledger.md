# SimCruise Unreal migration ledger

This is the Task 9 ledger from `docs/superpowers/plans/2026-11-10-simcruise-unreal-migration.md`. It lists every Godot runtime file under `godot-final:game/`, every scene and shader, every check, and every helper module and command. For each one it gives the Unreal destination, the stream that owns it, what must not be lost, a priority, and a planned classification: **ported**, **intentionally replaced**, or **retained** (shared runtime data/tool, or reference/source). Godot files may be removed only after their row reaches `done` with evidence (an Unreal check result, capture or receipt).

- Built against `unreal/client` at `1391ce1` (main `6cadf05` plus the Unreal project commits). Godot sources are unchanged from main.
- **The Godot client was deleted from the working tree on 11 November 2026** (round 2, owner decision "unreal only"). Every `godot-final:game/...` path below is read with `git show godot-final:game/<file>` (or browsed at the `godot-final` tag on GitHub); the data the Unreal client reads moved to `data/` (`data/cars`, `data/art/traffic`, `data/art/ground`, `data/tiles`, `data/observed`).
- Status was `todo` everywhere when the ledger was written. Round 2 (11 November 2026) marks rows with evidence: `done` (an Unreal check or capture shows it) or `partial` (what is and is not there). Round 2 also added what no Godot file had: Art Deco building recipes for the Miami Beach district, street lights with a night light pool, lit windows and neon, a low-beam cut-off, and a pedal-dependent automatic shift map (see docs/unreal-architecture.md, "Round 2: world detail"). Of the three uncovered P1 rows, InlineFourSound engine audio is done; the check.sh harness and ScriptErrorGuard are still open.
- **Priority:** 1 means it is needed for a first drivable build that keeps the car, roads and offline start true to the Godot client, or it holds calibration or provenance that cannot be rebuilt. 2 means it is needed for feature parity before Godot is retired. 3 means later work, reference material, or deletion.
- **Stream:** one of the five round-1 Unreal streams (vehicle physics core; world streaming: atlas client, tiles, terrain, roads; car presentation; lighting/environment; driving shell: input, cameras, HUD, rumble), or `later` when no round-1 stream owns it yet. Shared rows name every stream involved. The first stream named is the owner.
- **Conventions every port must honour:** Godot is metres, +Y up, -Z forward. Unreal is centimetres, +Z up, +X forward. Convert once at load and never in shared JSON. Godot FOV values here are vertical. Unreal FOV is horizontal unless the camera keeps Y FOV. Godot normal maps are OpenGL style, so flip G on import.

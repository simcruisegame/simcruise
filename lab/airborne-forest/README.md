## Authoring

The swath covers 1,590 × 760 m. The offline author sampled 58 octree nodes totaling 14,183,159 compressed LAZ bytes. It clipped 1,461,621 points from three flight lines, including 387,325 classified ground returns and 743 classified water returns. A 2 m grid normalizes first-of-multiple returns against local ground with a maximum supported gap under 7 m. Positive optical canopy evidence and neighboring elevated returns qualify a candidate peak. Height and eight directional measurements define an inferred crown. Where two flight strips overlap, incompatible local peaks are rejected. The satellite canopy check reused existing cached ranges and fetched nine additional ranges totaling 276,662 bytes in the first authoring run. The complete swath needs fifteen zoom-16 optical blocks. [USGS node hashes](../landscapes/wyoming/airborne-forest/lidar-nodes.json) · [WRI and Meta map, CC BY 4.0](https://registry.opendata.aws/dataforgood-fb-forestsv2/) · [Canopy-height publication](https://www.nature.com/articles/s41597-026-07882-0)

The author retained 2,453 crown peaks after ten road, building or water exclusions. Of these, 802 lie in cells where two vegetation maps support a prevailing evergreen forest. In mixed cells the renderer reuses a nearby modeled crown form where possible. Elsewhere, taper inferred from the laser returns selects a generic silhouette. The actual trunk position, species, bark and branch arrangement remain unknown. Existing city inventories retain precedence. Aerial mosaic RGB is sampled locally for far crowns and the terrain at roughly 6.5 m intervals. Acquisition dates can differ across the mosaic. Cells with incomplete vertices or more than 8.5 m relief across their roughly 6.5 m grid are left open. Twelve tiles supply 54,272 visual triangles and 2,766 supported water vertices. ## Reproduce

Run from the source root using Python with NumPy, SciPy, Pillow and laspy with lazrs. The existing game's compiled atlas helper supplies the public optical and map inputs. Prepare an empty working directory for each new site. The following commands fetch small source subsets into the specified cache, partition returns, author the data and generate a withheld-flight comparison.

```sh
python lab/airborne-forest/replay.py /tmp/forest-replay \
  --config lab/landscapes/wyoming/airborne-forest/survey.json \
  --atlas /path/to/atlas --cache /path/to/map-cache
```

An existing site cache replays offline. Add `--audit lab/landscapes/wyoming/airborne-forest/optical-inputs.json` to require the historical optical bytes and map geometry hashes. The public mosaic, forest maps and OpenStreetMap-derived tiles can be updated. The pinned cached replay reconstructed all 2,453 records, triangle and color bytes, and the local catalog byte for byte. Check the SHA-256 entries in *performance.json*. The two common far-crown meshes can be regenerated with `python lab/airborne-forest/far_mesh.py /path/to/game/data`. The author produces a single-site catalog. Merge an accepted site's row into the catalog when adding another verified region.

The input configuration must identify a suitable Web Mercator LAZ EPT survey, independent flight IDs, level ranges, site origin, elevation window and bounded swath. Confirm the vertical datum against the driving terrain, compare an unreconstructed photograph and check road, inventory and water exclusions before adopting a second area. The current accepted catalog contains one Wyoming site.

For the normal driving and optical checks, use a disposable copy of the game with its ordinary atlas helper at `../tools/atlas`. The headless command uses normal location selection and pedal input. The lab camera adapter writes only into the supplied scratch copy.

```sh
godot --headless --path /tmp/test/game --script "$PWD/lab/airborne-forest/drive_check.gd" -- --forest-drive after /tmp/after.json
godot --headless --path /tmp/test/game --script "$PWD/lab/airborne-forest/drive_check.gd" -- --forest-drive before /tmp/before.json
python lab/airborne-forest/stage_reference.py /tmp/test/game
godot --path /tmp/test/game --resolution 960x640 --audio-driver Dummy -- \
  --reference 43.753821 -110.624090 263.046 36.2437 /tmp/forest.jpg -.24 0 \
  --landscape-reference --snow-date 2025-05-30 --snow-study --ridge-study --summit-study --forest-depth-ab
python lab/airborne-forest/score.py forest /tmp
```

The native reference check writes four PNGs, one forest and one ground-only capture for each condition, and logs settled frame intervals and primitive counts. Historical snow and ridge layers require their normal public sources on a cold cache. Hansueli Krapf's May 30, 2025 photograph is resized and labeled in the CC BY-SA 4.0 comparison. The source reconstruction contains laser and map measurements. Branch geometry and texture reuse the credited game tree assets, including Poly Haven Pine Tree 01 under CC0.

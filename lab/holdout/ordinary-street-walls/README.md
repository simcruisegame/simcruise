# Two surveyed street walls

> Former name: this study was written when SimCruise was called "Sunday Driver"; the app, paths and commands it mentions under that name are now SimCruise.

Sunday Driver draws two partial, light-reactive exterior finishes beside normal searchable addresses. Search **220 E Washington St, Iowa City, IA** and travel west, or **310 Hennepin Ave, Minneapolis, MN** and travel northwest. The photographs cover upper ornament and masonry on one Iowa wall and a narrow bank of windows in Minneapolis. The game checks the complete mapped footprint, vertex order, edge, terrain and roof height. New geometry, a replaced wall survey, explicit wall finish tags, or an unsupported tile uses the existing renderer. Each match adds one six-vertex surface. The baked route has zero image-provider requests, a 100,221-byte combined runtime payload and no inference or collision changes.

## Reproduce the source textures

Copy this folder to a working directory with Python, NumPy, Pillow, SciPy and OpenCV. In that directory run:

```sh
python fetch.py
python bake.py
python records.py built
```

The downloader verifies six exact, separately credited photos against SHA-256 before use. Warm inputs require zero requests. The frozen replay on macOS reproduced both PNGs and both JSON files byte for byte. The two search tiles, static semantic masks and paired SIFT coordinates are included here. Removing a match cache reruns feature detection. The structural masks use the MobileNetV2 DeepLabv3 ADE20K authoring model described in `lab/semantic/README.md`. The authoring source retains the worker-independent verification evidence. No checkpoint or source panorama is bundled in the game.

The experiment sampled seven addresses in a ±105 m search. Two returned overlapping equirectangular panoramas with a verified mapped wall. The Portland planar views show different storefronts. Madison lacked enough separate map-aligned features on any candidate. Three catalog searches returned no panoramas. KartaView’s legacy nearby query returned HTTP 404 on the first four addresses. Panoramax’s catalog plus two training photos cost 713,463 bytes in Iowa and 822,015 bytes in Minneapolis. The third photograph used for evaluation cost another 253,553 and 322,405 bytes respectively. Cold address geocoding is separate. Native runtime applies only the two documented baked cases.

The source pair estimates spherical epipolar pose, triangulates static feature pairs and checks the nearest visible mapped wall. At least ten distinct metre-scale points, 30 m² of noncollinear support and two metres of lateral extent are required approximately. The accepted training baselines were 13.23 m and 12.93 m. The algorithm tests the ordinary and reversed panorama heading when positive-depth geometry disagrees with metadata. Minneapolis required the reversed hypothesis. Each atlas combines adjacent mutually visible cells where both photographs support the same plane against two competing planes. The renderer feathers coverage inside the verified extent, uses normal scene lighting and clips the detail at an updated roof. Photograph season, shadows, signs, reflective windows and source pose uncertainty limit what transfers between dates. The 4 m reported GPS accuracy is especially consequential on short baselines.

## Compare the third camera

The separately withheld camera contributes no atlas pixels. Orientation is fitted from static off-target features with a ±52° exclusion around the target. Save the four images at 900 × 600 through the normal game. Pass the following arguments after Godot's `--`. Output stems are arbitrary writable paths.

```text
--reference 41.6601497 -91.5328997 231.768986 55 /tmp/iowa-native.jpg -20.834411 0 --reference-epoch 1766437684 --wall-survey-ab
--reference 44.9810576 -93.2697017 320.799002 55 /tmp/minneapolis-native.jpg -18.696652 0 --reference-epoch 1745087293 --wall-survey-ab
```

The scorer uses the rendered coverage mask and the withheld structure mask. The Iowa evaluation additionally excludes the foreground streetlamp, banner and pole from the original photograph. Both before/after control repetitions were pixel-identical. Put the output images beside the images generated by bake.py and run `python score.py`. See `../views/ordinary-street-walls/receipt.json` and the two gallery sheets. The Iowa mean RGB error fell from 34.32 to 22.32 on 33,611 visible pixels, while local-detail correlation was effectively flat. Minneapolis mean RGB error fell from 38.11 to 29.56 on 11,575 pixels and local-detail correlation rose from 0.024 to 0.434.

Iowa State University’s independent 2020 LiDAR DSM and DEM yielded a 28.16 m median difference across 384 building interior cells. The competing map value is 34.6 m, and the unadjusted street cameras put the apparent eave near 23 m. These describe partly different physical surfaces and uncertain cameras. The game preserves its existing building geometry.

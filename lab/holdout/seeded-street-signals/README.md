# Three independently selected urban crossings

Run `python3 selection.py` here to reproduce the same three sites from the checked-in state probe (../../us-road-samples.json). Release 2026-10-21.0 of the Overture Base display archive supplied all three observed nodes. The ordinary KartaView/Panoramax lookup yielded usable imagery at zero of three points; Trenton returned some KartaView metadata but no accepted preview. A separately bounded Wikimedia Commons geosearch of 400 m at each original point found one usable photograph at each. The photographs were chosen for identifiable roads. The credited photographs, native before/after renders, capture dates, selection and registration receipt are in the [comparison directory](../views/seeded-signal-controls/).

The cameras use focal lengths equivalent to 29, 51 and 33 mm. Street-parallel edges supplied 33, 25 and 31 supporting perspective lines in Nevada, Indiana and New Jersey. The two phone compasses disagreed with the named streets. For those photographs, an independently identifiable junction center and a 1.65 m eye height placed the observer about 14.5 and 20.5 m from the raw geotags. A 12-pixel landmark tolerance at 680 px width produces about 4 m position uncertainty. Indianapolis uses the published Statehouse-area pin. The step and monument geometry do not establish precise camera height. Solar direction was computed at the EXIF wall-clock time and local timezone. Cloud cover and exposure were unverified. The photographs predate current map geometry, including Carson City's reconstruction.

The game requests the optional Overture base layer on the existing background canopy job when a streamed tile has multiple named motor roads and a main approach. The parsed zoom-13 record cache serves 64 zoom-16 road tiles. It accepts only a root OSM point with an explicit traffic-signal tag and ODbL provenance. A point must lie within 5 m of one junction formed by two distinct nonparallel road names with three to five resolved arms. The current transport layer vetoes nearby bridges and grade-separated roads. Nearby existing signal observations, ambiguous crossings and authored photo-capture tiles suppress this layer. One-way direction, road width, adjoining roads, tile borders and building footprints restrict fixture siting. The renderer only draws unlit, noncolliding signal heads. Pole layout, phases, crosswalks and road paint have no source in this record.

The three source tile payloads were 198,540, 573,915 and 227,264 bytes (range files in the archive cache; order varies). Shared archive header is 16 KiB. Leaf directory is 19–24 KiB. The range budget is 768 KiB and the catalog cap is 128 KiB, including negative cache with 15-minute retry interval. Cold shared-catalog runs needed 3/2/2 additional HTTP requests in the recorded order, and all six neighboring/repeated tile pairs reused the cache with zero HTTP. The first use of an entirely fresh cache can also require the catalog and normal canopy sources. A missing source leaves the street unchanged. This test does not estimate coverage across all U.S. intersections.

From the project root run `node lab/check_signal_controls.mjs`, `node lab/check_overture_heights.mjs` and `godot --headless --path game --script res://checks/SignalControlCheck.gd`. For a live sample, first run `bun helper/atlas.mjs tile CACHE 10965 25007` to cache the mapped street layer, then `bun helper/atlas.mjs canopy CACHE 10965 25007 --signal-controls`. In an isolated copy of the game with the editor's normal atlas executable available, copy the adjacent CrossSignal.gd into game/checks and run `godot --headless --path game --script res://checks/CrossSignal.gd`. This enters Carson Street through ordinary place selection, drives across the source node using the normal accelerator and records tire contacts. The tested northbound crossing traveled 43.05 m with all four wheels in contact, starting 27.79 m before the observed crossing and finishing 15.26 m beyond it.

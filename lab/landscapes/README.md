# Regional terrain and photographic comparison

Each district contains a licensed source photograph and two Godot Metal frames at the same world pose. The photography is credited in views.json and the offline street comparison gallery. Both Commons photographs are shared under CC BY-SA 4.0. The resized photos are comparative references and never serve as textures for these landscapes.

**Wyoming.** The camera location and lens are from the original EXIF. A single [USGS GNIS summit](https://edits.nationalmap.gov/apps/gaz-domestic/public/search/names/1609199) anchored the approximate heading and pitch. The 23 separate marked positions in score.py remain outside that summit. The script refines each photographic edge within four vertical pixels, then estimates the game silhouette from three consecutive land-colored pixels. This is image-space agreement at one known camera. Trees, snow and seasonal growth are separate.

**Utah.** The geotagged image contains the highway and distinct mesa outlines. Heading, field of view and pitch are estimates. The score measures vertical discrepancy on outer columns at a fixed pose. A second diagnostic uses only the center strip for a vertical offset. Color thresholds can misidentify the older panorama near the horizon. This was the development location.

To reproduce the image measurements use Python with Pillow, NumPy and SciPy. Run `python wyoming/score.py` and `python utah/score.py before after` from this directory. The Wyoming script writes its score and annotated frames next to the images.

**Geographic streaming.** When the car reaches a new zoom-13 region, the helper reads cached Terrarium elevations, samples a 90 km square into 1,025 × 1,025 heights, and simplifies it using the open-source [Martini](https://github.com/mapbox/martini) triangulator. Near the horizon the engine applies Earth curvature. Up to four higher-detail terrain tiles follow the elevated skyline, with U.S. National Map imagery supplying ground color. The current regional projection approximates horizontal scale from the center latitude. The inner driving tiles supply tire contacts. Old regional terrain can remain visible during a neighboring-region handoff. An offline revisit reuses the cooked mesh; first visits require access to the source providers.

The coasts use [Natural Earth 5.1.1](https://www.naturalearthdata.com/downloads/10m-physical-vectors/10m-ocean/). build_coast.py reproduces the compact distant-water mask from the upstream ZIP. The coastline has approximately 435 m north–south sampling and is used only on distant terrain. Below-sea-level inland ground remains eligible.

**Testing.** `bun lab/check-regional-terrain.mjs /path/to/dedicated/cache` checks mesh format, index limits, actual geography, ocean/inland distinctions and revisiting while its source reader is disabled in six districts. For an engine capture use the application arguments `-- --complete-reference --landscape-reference --reference LAT LON HEADING FOV output.jpg PITCH_DOWN`. Set the window to the original photo dimensions. Add `--landscape-cost` to sample alternating hidden/visible terrain after loading. Metal timing here is elapsed whole-frame time. It varies with scene, window size, display and other running programs.

**Detecting bad source elevations.** Two near-flat regions contained isolated artificial pits. A fresh [USGS 3DEP](https://www.usgs.gov/3d-elevation-program) sample placed the Nebraska control at 373.63 m; the corrected game mesh gives 375.27 m. Death Valley retains its real negative heights. [Method, constraints and measurements](../regional-height-outliers.md). A verification request shares the four-tile skyline refinement budget.

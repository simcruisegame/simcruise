## Repeat locally

The packaged game reads only two small per-tile files. Authoring uses Python, NumPy and Pillow. The archive contains a 2023 and 2025 ortho crop with bounds and original request URLs, the immutable captured map and inventory responses, direction-checked selection metadata, and the road vectors from the normal game tile.

From this directory, run these commands with an empty temporary work directory and a Godot project with its editor imports available.

```sh
mkdir -p /tmp/medford-replay
unzip -q medford-inputs.zip -d /tmp/medford-replay
python3 author.py --work /tmp/medford-replay --site /tmp/medford-replay/survey --game-map /tmp/medford-replay/game-map.json --output /tmp/medford-replay/output
cmp /tmp/medford-replay/output/measured-section-19827-24228.json ../../game/data/measured-section-19827-24228.json
cmp /tmp/medford-replay/output/measured-section-19827-24228.png ../../game/data/measured-section-19827-24228.png
godot --headless --path ../../game --script "$PWD/verify.gd" -- /tmp/medford-replay/game-map.json /tmp/medford-replay/survey/geometry-proof.json
```

For another Massachusetts site, fetch the bounded state and federal records with `python3 inventory.py WORK KEY LAT LON` and the signed OpenFreeMap geometry with `bun vector.mjs WORK KEY LAT LON`, using the project’s existing JavaScript dependencies. Supply the observed travel heading to `python3 select.py WORK SITE KEY LAT LON HEADING`. For an accepted route, `python3 aerials.py SITE` fetches the two candidate epochs. Supply the normal atlas helper’s z16 tile JSON to `author.py`. The current author supports only two-lane directional Massachusetts events with a bituminous right shoulder, two independent optically registered acquisitions, and a supported interval within one game tile. Missing input or an insufficient fit prevents output. Profiles still need an independent street-photo comparison and a normal-game check before inclusion. The proof script `drive_check.gd` takes `--section-proof before|after ABSOLUTE_OUTPUT_PREFIX`. It selects ordinary Medford coordinates and drives using normal player inputs.

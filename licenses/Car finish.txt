Player-car finish · game/CarFinish.gd reshapes the existing CC BY-SA 4.0 exterior (game/art/miata.glb) at run time with smooth displacement fields and adds generated geometry: wrap-around tail-lamp lenses and gaskets, panel shut lines, door mirrors, door pulls, rear side reflectors and the number-plate mount. The reshaped exterior and the photographed lamp textures it carries remain under CC BY-SA 4.0 as before; the generating code is part of the SimCruise code (MIT). No manufacturer marks are drawn.
Sport wheel and tyre · game/SportWheel.gd builds the five-spoke 15-inch casting, centre cap, 195/50R15 tyre and brake caliper procedurally. The casting proportions were measured from reference photographs; no photograph pixels are used. Authored for SimCruise; see the project MIT license.
Tuned-roadster wheel and spoiler · game/TunedWheel.gd builds a generic 17-inch ten-spoke alloy (an original design, not any maker's wheel), its 205/40R17 tyre, the 269 mm disc and a silver caliper procedurally; CarFinish.gd lays a small deck-lid lip spoiler (original shape) on the lid of the tuned roadster. No photograph pixels, maker designs or marks are used. Authored for SimCruise; see the project MIT license.
